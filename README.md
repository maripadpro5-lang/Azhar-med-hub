# Azhar-med-hub
AZHAR MED HUB منصة طبية تعليمية متكاملة لطلاب طب الأزهر، تجمع الأدوات الدراسية والخدمات الجامعية في مكان واحد. توفر ترجمة المصطلحات، والقاموس الطبي، والجداول، ومعلومات التسجيل، ومصادر المذاكرة والحلول، وموارد Incision Academy، لتسهيل الوصول للمعلومات وتنظيم الدراسة وتحسين التجربة التعليمية بكفاءة ووضوح.  تطوير: Mohamed Ahmed Raafat Saif El Nasr
